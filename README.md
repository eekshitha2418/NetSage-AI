# NetSage AI: AI-Assisted Network Troubleshooting

## Overview

NetSage AI is an AI-assisted network troubleshooting system designed to improve the accuracy and reliability of network diagnosis and recommendations.

## Key Contributions

- Developed deterministic rule checks to validate AI-generated network troubleshooting results against network evidence and predefined rules.
- Performed human review to identify inconsistencies and improve the accuracy and reliability of AI-generated troubleshooting recommendations.
